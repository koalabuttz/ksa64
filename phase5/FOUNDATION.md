# Phase 5 spatial numeric foundation

The generated `contract-v1.json` is the authoritative source for frames, scales, ranges, widened products, cadence, reference mission, and frozen planar evidence. `scenario-v5.schema.json` constrains the reviewed human-readable source. `generated/contract_v1.rs` is the only Phase 5 constants file compiled into the portable core.

The first implementation gate does not introduce spatial dynamics. It establishes immutable inputs and proves that merely adding the Phase 5 namespace cannot change the accepted planar system. Vector, quaternion, rigid-body, flexible-body, and mission code enter through later independently accepted gates.
